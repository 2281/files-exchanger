# Файлообменник - План реализации

## Описание проекта
Файлообменник между пользователями внутри одной локальной сети с веб-интерфейсом для управления файлами.

## Требования к функционалу (как указано в README.md)

### Основные возможности:
1. Просмотр списка файлов в файлообменнике через веб интерфейс
2. Загрузка и удаление файлов и папок через веб интерфейс  
3. Создание прямых ссылок на файлы и папки
4. При скачивании папки с файлами, она архивируется в zip файл и скачивается как zip

## Технологический стек

### Backend Framework:
- **FastAPI** - для создания REST API и веб-интерфейса
- Преимущества: высокая производительность, автоматическая документация, типизация

### База данных:
- **SQLite** - для простоты реализации (данные хранятся локально)
- Возможно расширение на PostgreSQL при необходимости масштабирования

### Хранилище файлов:
- **Локальная файловая система** - файлы сохраняются локально в указанной директории
- Поддержка папок и файлов разного типа

### Фронтенд:
- **HTML/CSS/JavaScript** - базовый веб-интерфейс
- Возможно использование фреймворка (Angular, React) при расширении функционала
- Bootstrap или Tailwind CSS для стилизации

### Дополнительные технологии:
- **Python ZipFile** - для архивации папок в ZIP формат
- **Docker** - для контейнеризации (опционально)

## Основные функциональные модули

### 1. API Модуль (`api/`)
Создание REST API для взаимодействия с сервисом:
- GET `/files` - получение списка файлов и папок
- POST `/upload` - загрузка файлов и папок 
- DELETE `/file/{id}` - удаление файлов и папок
- GET `/download/{id}` - скачивание файла или архивированной папки
- GET `/link/{id}` - получение прямой ссылки на файл/папку

### 2. Модели данных (`models/`)
- `File` - модель файла с полями: id, name, path, size, type, created_at, updated_at
- `Folder` - модель папки с полями: id, name, path, created_at, updated_at

### 3. Сервисы (`services/`)
- `FileService` - основная логика работы с файлами
- `StorageService` - управление операциями хранения

### 4. Хранилище (`storage/`)  
- Работа с локальной файловой системой (создание, удаление, копирование файлов)
- Поддержка архивации папок в ZIP

### 5. Веб-интерфейс (`templates/`, `static/`)
Базовый HTML интерфейс для:
- Просмотра списка файлов
- Загрузки новых файлов 
- Удаления файлов и папок
- Отображения прямых ссылок

## Основные API эндпоинты

### 1. Получение списка файлов
```
GET /api/files
```

### 2. Загрузка файла/папки
```
POST /api/upload
Content-Type: multipart/form-data
Parameters:
- file: загружаемый файл
- folder: указание папки для загрузки (опционально)
```

### 3. Удаление файла или папки
```
DELETE /api/file/{id}
```

### 4. Скачивание файла или архива
```
GET /api/download/{file_id} 
```

### 5. Создание прямой ссылки
```
POST /api/link/{file_id}
Response: {
    "url": "http://localhost:8000/api/download/xyz123"
}
```

## Реализация ZIP архивации

Для скачивания папок как ZIP:
- При вызове `GET /api/download/{folder_id}` проверяется тип элемента
- Если это папка, создается временный ZIP архив 
- Архив возвращается пользователю с соответствующим заголовком
- Временный архив удаляется после скачивания


## Безопасность

- Локальный доступ только внутри сети (в пределах локальной сети)
- Базовая валидация типов и размеров файлов
- Проверка путей для предотвращения атак типа path traversal
- Временная защита от перегрузки сервера

- Поддержка различных типов хранилищ (локальное, облачное)
