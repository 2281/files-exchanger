### Файлообменник между пользователями внутри одной локальной сети. 

## Реализовано

### 1. Возможность просматривать список файлов в файлообменнике через веб интерфейс 
✅ Реализовано - список файлов отображается на главной странице

### 2. Возможность загружать и удалять файлы и папки в файлообменнике через веб интерфейс
✅ Реализовано - возможность загрузки и удаления файлов и папок через web-интерфейс

### 3. Возможность создавать прямые ссылки на файлы и папки
✅ Реализовано - кнопка "Ссылка" в интерфейсе для создания прямой ссылки 

### 4. При скачивании папки с файлами, она архивируется в zip файл и скачивается zip файл
✅ Реализовано - при скачивании папки создается временный ZIP архив

## Основные функции:

- Веб интерфейс для просмотра и управления файлами  
- Загрузка файлов и папок через веб-интерфейс
- Удаление файлов и папок
- Создание прямых ссылок для файлов
- Автоматическая архивация папок при скачивании в ZIP формате
- Проверка размера файлов (до 100MB)
