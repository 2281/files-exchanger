# Файлообменник

Файлообменник - это веб-приложение для обмена файлами внутри локальной сети.

## Функциональность

- Загрузка файлов через веб-интерфейс
- Список загруженных файлов с информацией (имя, тип, размер, дата создания)
- Скачивание файлов по прямой ссылке
- Удаление файлов
- Создание прямых ссылок на файлы

## Установка

1. Установите зависимости:
```
pip install -r requirements.txt
```

2. Запустите приложение:
```
python main.py
```

3. Откройте в браузере: http://localhost:8001

## API

- GET /api/files - Получить список файлов
- POST /api/files/upload - Загрузить файл  
- DELETE /api/files/{file_id} - Удалить файл
- GET /api/files/download/{file_id} - Скачать файл
- POST /api/links/{file_id} - Создать прямую ссылку

## Особенности реализации

- Файлы хранятся в локальной директории storage/
- Метаданные файлов хранятся в SQLite базе данных (files.db)
- Интерфейс реализован на Jinja2 шаблонах с Bootstrap
- JavaScript логика интерфейса включена в статические файлы
