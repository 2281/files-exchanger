# Файлообменник

Файлообменник - это веб-приложение для обмена файлами внутри локальной сети.

## Функциональность

- Вход по email: пароль генерируется и приходит на почту, логин — адрес email
- Личное хранилище: файлы и папки пользователя видит только он
- Пометка «видна всем»: файл или папка (со всем содержимым) появляется в списке у всех пользователей, изменять их может только владелец
- Загрузка файлов, создание папок, удаление
- Скачивание файлов; папка скачивается как ZIP-архив
- Временные ссылки (до 30 дней) на любой доступный файл или папку — скачивание по ссылке без входа, ссылку можно отозвать

## Установка

1. Установите зависимости:
```
pip install -r requirements.txt
```

2. Настройте отправку почты: скопируйте `.env.example` в `.env` и заполните параметры SMTP.
   Без настройки SMTP письма с паролями печатаются в консоль сервера — удобно для разработки.

3. Запустите приложение:
```
python main.py
```

4. Откройте в браузере: http://localhost:8001

## API

Все эндпоинты `/api/files` и `/api/links` требуют входа (cookie сессии), иначе возвращают 401.

Аутентификация:
- POST /api/auth/request-password - Отправить пароль на email (`{"email": "..."}`); новый пользователь создается автоматически
- POST /api/auth/login - Войти (`{"email": "...", "password": "..."}`)
- POST /api/auth/logout - Выйти
- GET /api/auth/me - Текущий пользователь

Файлы:
- GET /api/files - Свои файлы и папки верхнего уровня и общие объекты других пользователей
- POST /api/files/upload - Загрузить файл в свой корень
- POST /api/files/folder - Создать папку (`{"name": "...", "parent_id": null}`)
- GET /api/files/folder/{folder_id}/list - Получить папку и её содержимое
- POST /api/files/folder/{folder_id}/upload - Загрузить файл в свою папку
- PATCH /api/files/{file_id} - Изменить видимость (`{"is_public": true}`)
- DELETE /api/files/{file_id} - Удалить свой файл или папку со всем содержимым
- GET /api/files/download/{file_id} - Скачать файл (папка скачивается как ZIP)

Временные ссылки:
- POST /api/links/{file_id} - Создать ссылку (`{"expires_in_hours": 168}`, максимум 720)
- GET /api/links - Свои действующие ссылки
- DELETE /api/links/{link_id} - Отозвать ссылку
- GET /s/{token} - Скачать по ссылке (без входа)

## Особенности реализации

- Файлы хранятся в `storage/<id пользователя>/`, структура папок повторяет структуру на диске
- Пользователи, сессии, метаданные файлов и ссылки хранятся в SQLite (files.db)
- Пароли хранятся как хеши scrypt; токены сессий и ссылок — как хеши SHA-256, поэтому ссылку можно увидеть только при создании
- Ссылка действует, пока не истек срок и пока у ее создателя есть доступ к объекту
- Интерфейс — Jinja2 шаблоны (templates/index.html, templates/login.html) с Bootstrap, JavaScript в static/js
- HTTPS пока не настроен: после его настройки установите `COOKIE_SECURE=true`
